# Development Memory

- Engine: Babylon.js 9.22.1, React chỉ cung cấp khung và UI overlay.
- Camera cố định đặt sau người chơi; đường chạy dịch chuyển về camera để tạo cảm giác chạy vô hạn.
- Không tải asset cục bộ lớn vào dự án. Tất cả minh hoạ dùng URL `/manus-storage/...` bền vững của dự án.
- `?demo` dùng spawn seed cố định và lái tự động để screenshot chứng minh gameplay đang diễn ra.
- Các tên nhân vật là lựa chọn fan-concept; hình 3D runtime là mascot nguyên gốc lấy cảm hứng kawaii, không dùng file ảnh thương hiệu bên thứ ba.
